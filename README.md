# Flutter Getting Started

App Flutter di esempio con un contatore incrementabile tramite il pulsante `+`.

## Requisiti

- Flutter SDK con Dart.
- Xcode su macOS per l'esecuzione su iOS.
- Android SDK per l'esecuzione su Android.

## Avvio

Dalla cartella del progetto:

```sh
flutter pub get
flutter run
```

## Verifica

```sh
flutter analyze
flutter test
```
